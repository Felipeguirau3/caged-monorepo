# Analises Exploratorias

Armazene aqui os notebooks de exploracao dos dados do CAGED. Dependencias de
Jupyter podem ser adicionadas ao grupo de desenvolvimento quando necessario.

Use o ambiente `.venv` da raiz e importe o pacote `caged_analytics` para
reaproveitar transformacoes. Mova regras reutilizaveis para esse pacote.
Nao versione saidas contendo dados restritos ou grandes volumes de registros.
